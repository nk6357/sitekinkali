# Развёртывание Кинкали

## Переменные окружения

Скопируйте список ключей из `.env.example`. Реальные пароли и секреты не
добавляйте в Git.

Обязательные значения:

- `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`
- `SMTP_USER`, `SMTP_PASSWORD`
- `SMTP_FROM`, `SMTP_FROM_NAME`
- `ADMIN_EMAIL`
- `ALLOWED_ORIGINS`

Остальные значения уже имеют безопасные значения по умолчанию, но их можно
переопределить.

## Vercel

1. Откройте проект в Vercel.
2. Перейдите в **Settings → Environment Variables**.
3. Добавьте каждую переменную из `.env.example` для `Production`, `Preview` и
   `Development`. Для `ALLOWED_ORIGINS` укажите адреса Vercel и Timeweb через
   запятую, без завершающего `/`.
4. После изменения переменных выполните новый Deploy.

Локально переменные можно получить командой:

```bash
vercel env pull .env.local
```

`.env.local` уже исключён из Git.

## Timeweb

Для приложения Node.js добавьте те же переменные в панели приложения:
**Настройки приложения → Переменные окружения**. Названия разделов могут
незначительно отличаться в зависимости от типа сервиса Timeweb.

Команды приложения:

```text
Build: npm ci && npm run build
Start: npm run dev:server
```

Если статический сайт и API размещаются на разных доменах, добавьте адрес
статического сайта в `ALLOWED_ORIGINS` и направьте `/api/orders/send-email` на
Node.js-приложение через reverse proxy.

## SMTP

Используйте отдельный почтовый ящик домена и пароль приложения/SMTP. Порт `465`
обычно требует `SMTP_SECURE=true`; порт `587` — `SMTP_SECURE=false` с
последующим TLS. Обычный пароль от личной почты хранить в проекте нельзя.
